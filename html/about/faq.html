常见问题

本页收录了一些有关合作任务和本站的常见问题。

游戏玩法

观看录像时，怎样获得埃蒙单位的视野？

首先找到你能看到埃蒙某个单位或建筑的时刻。点击该单位并按住“V”键，即可显示埃蒙的所有单位。

请注意，如果所选单位或建筑死亡，你会失去视野。要持续保有视野，最好在仍按住 V 键时，点击某个不会被清理区域内的埃蒙建筑来转移视野。

合作任务玩家最常犯的严重错误是什么？

过度专注于额外目标。与任务胜利相比，额外目标提供的经验值很少。然而，许多玩家一心完成额外目标，最后却输掉整个任务。像死亡摇篮这样的任务尤其容易让缺乏经验的玩家落入这个陷阱。

关于本站

如何参与贡献？

非常感谢你的关注。请访问 starcraft2coop.com 的 GitHub 仓库。

这些数据从何而来？

本站所有数据均由 Aommaster 亲自查阅地图文件，以及 StarCraft 编辑器的触发器编辑器和数据编辑器中存储的信息而得。

对局解说使用什么录像界面？

Aommaster 曾使用自己编写的自定义录像界面，专供本站内容使用。

如果我想了解其他信息呢？

你可以前往 Reddit 的 /r/starcraft2coop 社区或 StarCraft II 合作任务 Discord 服务器交流。

我发现页面中有错误。

你可以在 starcraft2coop.com 的 GitHub 仓库中提交修正。

你们应该针对不同敌方阵容、地图和指挥官组合推荐部队配置

这是本站经常收到的请求，但我们出于以下原因，一直没有加入此类信息：

  • 推荐特定部队配置，容易让玩家误以为对付某种敌方阵容只能使用这些单位。本站的目标是为玩家提供资料和技巧，并鼓励大家更深入地思考合作任务背后的策略
  • 常规难度下或许有推荐的部队配置，但面对突变因子时还需要额外考量
  • 合作任务进行平衡调整时，部队中的单位组合可能改变，从而增加额外的维护负担

我有建议、技巧或其他信息想补充。

你可以在 starcraft2coop.com 的 GitHub 仓库中参与贡献。

如何支持本站？

我们不需要资金支持，但非常欢迎向 starcraft2coop.com 的 GitHub 仓库贡献代码。

特别感谢 CtG0526，他从本站创立之初便一直支持并帮助推广本站！

其他问题

你们是谁？

本站最初由 Aommaster 编写。合作任务于 2015 年 11 月上线后，他便开始游玩，并在 2018 至 2022 年间直播合作任务。他在所有服务器上都拥有 1,000 级巅峰等级账户。你也可以访问他的个人网站了解其他兴趣，或加入他的 Discord。

本站目前由 Serine 托管。

Aommaster 的天梯排名是多少？

他只玩合作任务。事实上，他从未打过哪怕一场天梯比赛，一场都没有。

以前不是有合作任务锦标赛页面吗？

是的，我们举办过两届锦标赛，分别在 2019 年和 2021 年。锦标赛录像存档仍然保留，旧的报名页面也仍可访问。
