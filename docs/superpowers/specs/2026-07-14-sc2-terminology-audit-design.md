# 《星际争霸 II》简体中文术语审校设计

## 目标

统一全站用户可见的建筑、单位、种族、属性、技能、升级、精通和威望名称，优先采用暴雪《星际争霸 II》简体中文客户端术语；无法确认官方译名的合作任务专属内容进入例外表。

## 数据边界

- 修改 `source-data` 和 `source-html` 中的用户可见中文。
- 保留内部 ID、basename、路由 slug、文件名、数值、占位符、图片和媒体 URL。
- 同一英文术语在所有页面使用同一个简体中文名称。
- 生成目录只通过现有生成脚本更新，不直接手工修正生成结果。

## 术语来源与例外

术语表以官方简体中文客户端/暴雪简体中文资料为首选来源；官方没有对应译名时，使用社区通行译名并记录英文键、采用译名、来源和备注。繁体中文名称只作为交叉核对，不直接复制为简体中文。

## 审校流程

1. 扫描 `playerunits.json`、`amonunits.json`、`playerupgrades.json`、`playertalents.json`、指挥官页面和通用 UI 文本。
2. 生成英文键到现有中文的差异清单，重点检查建筑/单位重复名、模式后缀和同义词。
3. 更新 `translation/glossary.json` 及必要的数据源；为争议术语添加例外说明。
4. 运行术语一致性测试、翻译验证、PHP/Bun 测试和完整静态构建。
5. 抽查单位页面、指挥官页面、升级/精通页面和搜索结果，确认站内链接、ID 和媒体未变化。

## 验收标准

- 建筑/单位页面不再出现同一英文键的多个中文译名。
- 官方术语优先项全部通过术语表验证。
- 未确认项目均在例外表中可追溯。
- 生成站点构建成功，Pages 部署成功，代表页面显示修正后的名称。
